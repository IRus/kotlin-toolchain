# Publishing

The publishing workflow depends on what you build and where you distribute it. Choose the scenario that matches your
project:

<div class="grid cards" markdown>

-   :simple-apple: [iOS applications](../publishing_ios.md)

    ---

    Configure signing, create a release archive, and upload an iOS application to App Store Connect for TestFlight or
    App Store distribution.

-   :android-head-flat: [Android applications](../publishing_android.md)

    ---

    Create an upload key, build a signed Android App Bundle, and upload it to Google Play.

-   :material-library: [Libraries](../publishing_libraries.md)

    ---

    Publish a JVM library to a Maven repository or Maven Central using the `kotlin publish` command.

</div>
